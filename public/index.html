JUOST

Party game: hold still when the beat slows, move when it races. Last phone standing wins.

Host TV or laptop — create the room and run the music Play Phone — join with the room code and use motion (or tap)
How to play
1. Host opens Host on the big screen and shares the 4-letter code.
2. Everyone joins on phones from Play (same Wi‑Fi).
3. First to the target score wins the match.
4. On iOS, use HTTPS (see README) for motion — or use Tap to move.
